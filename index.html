Persistence and technical details
If a setting is lost when the keyboard reboots – for example when you flip the mode switch – the save step is the suspect. The sources disagree here, so both variants are selectable. Applies to lighting, clock and standby.
Test procedure: apply a setting, unplug the cable, wait five seconds, plug it back in. If the setting survives, that variant writes to flash.
Sequence: START 04 18, MODE_CFG 04 13, MODE_DATA, SAVE 04 02. In the data packet byte 0 is the effect value, bytes 1–3 are R/G/B, byte 8 the rainbow flag, bytes 9–11 brightness, speed and direction, trailer 55 AA on bytes 14/15.

Advanced options
Payload = 256-byte header plus frames of 32768 bytes each, padded to multiples of 4096. Frame delays are stored as milliseconds divided by two, so 2 to 510 ms. The two variants come from two sources that disagree on three bytes.

How to make it permanent
      
Make permanent downloads a startup file. Then run these three lines in Terminal:

      
mkdir -p ~/Library/LaunchAgents
mv ~/Downloads/de.local.ak820.keymap.plist ~/Library/LaunchAgents/
launchctl load -w ~/Library/LaunchAgents/de.local.ak820.keymap.plist

      
Without this the mapping is gone after a restart. Key combinations such as Cmd plus Space are not possible – only key to key.
